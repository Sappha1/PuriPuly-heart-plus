## r338 — 2026-07-30

- **목소리 이름을 바꾸면 그 사람의 기록이 모두 함께 바뀝니다.** 같은 사람을 여러 메시지에서 따로 지정했더라도, 대화 기록에 있는 그 사람의 항목이 한 번에 모두 갱신됩니다(클릭한 하나만이 아닙니다)
- **다른 화자에게 남의 이름이 붙지 않습니다.** 예전에는 인식될 만큼 닮지 않은 목소리라도 같은 대화 속 목소리와 어렴풋이 비슷하기만 하면 그 이름을 물려받을 수 있었습니다. 이제는 확신이 없으면 이름을 추측하지 않고 "Speaker N"으로 표시합니다
- **새 기능: 설정 › 오디오 › 저장된 목소리.** 이름을 지정한 사람들과 각자의 성문 개수를 확인하고, 이름을 바꾸거나 삭제할 수 있습니다. 그 사람이 다시 말할 때까지 기다릴 필요가 없습니다
- 저장된 목소리 삭제가 즉시 반영됩니다(앱을 다시 시작할 때까지 남아 있지 않습니다)

## r336 — 2026-07-30

- **클립보드 자동 번역을 삭제했습니다.** 켜져 있으면 복사한 내용이 전부 번역되어 VRChat 채팅창으로 전송됐습니다. 브라우저에서 복사한 비밀번호나 카드 번호가 주변 모두에게 보이는 상태였습니다. 기본값은 꺼짐이었지만 설정 자체를 없앴습니다
- 현재 제공자가 무시하는 설정은 흐리게 표시되고 어떤 제공자인지 밝혀 이유를 알려줍니다. Google 번역·DeepL·Bing·Papago에서는 시스템 프롬프트와 문맥이 전송되지 않으며, 사용자 단어는 Deepgram·Soniox·Qwen ASR 0.6B(로컬)에서만 동작합니다
- 사용자 단어 설명이 틀렸습니다 — 기본값인 로컬 Qwen 모델이 빠져 있었습니다. 이제 단어가 언어별로 저장된다는 점과 엔진별 개수 제한(50개, 로컬 모델은 12개)도 안내합니다
- 프롬프트 탭을 없앴습니다: 시스템 프롬프트는 API 탭의 모델 선택 아래로, 사용자 단어는 오디오 탭의 음성 인식 아래로 옮겨, 동작 여부를 결정하는 선택 바로 옆에 두었습니다
- 설정 이름을 표준 용어로 되돌렸습니다 — 마이크 감도, 마이크 자동 게인, 마이크 노이즈 억제, 오디오 호스트, 사용자 단어 — r335의 쉬운 말 표현은 취소했습니다
