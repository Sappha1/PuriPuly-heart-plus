## r319 — 2026-07-30

## r318 — 2026-07-30

- 新機能：話者識別。受信した声はチャットで「話者1」「話者2」…とタグ付けされ、グループ通話で誰の発言か分かるようになります — タグをクリックすると知っている声に名前を付けられ、名前を付けた声は今後のセッションでも認識されます。声紋はこのPCにのみ保存され（settings の隣の小さな voices.json）、決してアップロードされません。設定スイッチ：「話者を識別」（デフォルトでオン）。非常に短い発話はタグ付けされず（信頼できる声紋には音声が短すぎるため）、圧縮された通話では似た声が時々混同されることがあります

## r317 — 2026-07-30

- アプリが起動時に自己更新するようになりました：自動ダウンロードが起動後10分以内に完了すると、そのまま新しいビルドで再起動します（セッション設定は自動復元されます）— アプリを起動することは最新版を起動することになりました。セッション中に見つかった更新は引き続き再起動ボタンを待ちます。既存の「更新を自動ダウンロード」設定でオフにできます
- 更新チェックが中国本土でも動くようになりました：GitHub の API がブロックされている場合、jsDelivr ミラー経由でバージョン情報を読み取るため、更新の有無と内容は引き続き確認できます
- オーバーレイの字幕が1〜2語だけを単独の行に残さなくなりました：わずかにはみ出す行は少し縮小して1行に収め、本当に長い行は自然な区切りでバランスの取れた2行に分割します

## r316 — 2026-07-29

## r315 — 2026-07-29

- オーバーレイが表示されないのに「接続中」と表示され続ける問題を修正：まれな起動タイミングの衝突（最初の字幕がリサイズ中に到着）でオーバーレイのメッセージ受信が静かに死ぬことがありました — ウィンドウは画面上にあり接続も生きているのに、手動で切り替えるまで何も表示されない状態です。オーバーレイはアプリの毎秒のハートビートを監視し、30秒途絶えると自動的に再起動します。静かな失敗経路はログを残して再起動し、アプリ側も死んだ接続を検出します

## r314 — 2026-07-29

## r313 — 2026-07-28
